## GitHub Pages Hosting (Free Installable App)

### Steps to host on GitHub:

1. **Create GitHub Repo:**
   - Go to github.com → New Repository
   - Name: `arabs-mandi-billing`
   - Public, no README (we have files)

2. **Upload these files:**
   - Drag & drop all files from this folder to GitHub
   - Or use GitHub Desktop / git push

3. **Enable GitHub Pages:**
   - Repo Settings → Pages
   - Source: Deploy from a branch
   - Branch: main / root
   - Save → Wait 1-2 mins
   - Your link will be: `https://YOUR_USERNAME.github.io/arabs-mandi-billing/`

4. **Installable PWA:**
   - Open that link on Android phone in Chrome
   - Chrome menu → Add to Home Screen / Install App
   - App installs like real APK with your banner icon!

5. **Convert to APK (Thermal Printer Ready):**
   - Once GitHub Pages link is live, go to:
     - **pwa2apk.com** → Paste your GitHub Pages URL → Build APK
     - Or **webintoapp.com** → Paste URL → Enable Bluetooth + Internet permission → Build APK
     - Or **appsgeyser.com** → Website → Paste URL
   
   - Your GitHub link is already thermal-print optimized (80mm/58mm)
